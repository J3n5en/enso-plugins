# Walkthrough

侧栏里的变更讲解。选定一段 Git diff，按读得通的顺序拆成步骤：每一步有标题、说明，以及它对应的代码，一次只看一步。说明来自 diff 和提交说明，不依赖模型；文字可以改。

## 使用

1. 打开侧栏「讲解」，或在输入框执行 `/enso.walkthrough:open`。
2. 选择范围：
   - **当前会话**：有 Enso 检查点时，讲解会话开始之后的提交，以及还没提交的改动；还没有检查点时，改用未提交改动。
   - **未提交**、**暂存区**、**相对基准分支**。
   - **提交范围**：最近若干次提交，或 `HEAD~5..HEAD` 这样的范围。每次提交一步，按时间从早到晚。
3. 点「生成讲解」。用上一步 / 下一步，或 `←` `→`，一次看一步。
4. 「编辑文字」可以改这一步的标题和说明，也可以改整篇的标题和摘要。同一处改动再次生成时，改过的文字会留下来。
5. 「复制」把讲解变成 Markdown。

生成文件、锁文件和二进制只列在「未展开」里。Diff 特别大时会截断，并在说明里写明。

## Agent 工具

| 工具 | 作用 |
| --- | --- |
| `walkthrough_build` | 按选定范围生成讲解并显示在侧栏 |
| `walkthrough_edit` | 修改某一步或整篇的文字 |
| `walkthrough_current` | 读取当前项目已保存的讲解 |

## 数据

每个项目一份，保存在插件数据目录的 `walks/`。讲解记的是 diff 结构、你改过的文字和读到哪一步，不读取 Claude Code 的会话记录。

## 权限

| 权限 | 用途 |
| --- | --- |
| `ui.view` | 打开侧栏页面 |
| `ui.clipboard` | 复制 Markdown |
| `fs.read` | 读取项目里尚未被 Git 跟踪的文件 |
| `session.read` | 确定当前会话，以便对照 Enso 检查点 |
| `agent.tool` | 提供上面的工具 |
