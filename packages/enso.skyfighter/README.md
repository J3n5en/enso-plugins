# 雷霆战机 · 天穹远征

侧栏里的纵向弹幕射击。选一架战机，穿过五个空域，在漂移弹和激光之间找路，拾取四色武器，并在关间三选一强化。

画面由程序绘制，声音由 Web Audio 实时合成。不联网，不读工作区文件。最高分、声音开关和「减少装饰动态」记在插件自己的页面存储里。

## 怎么玩

1. 打开侧栏「雷霆战机」，在机库里选 **鹰隼**、**棱镜** 或 **堡垒**。
2. 选标准或街机，以及完整战役或单关演练，点「开始远征」。战机自动开火。
3. 击落敌机后追逐漂浮补给。同色升级，换色会保留各自等级。
4. 每关至少战斗两分钟，第 88 秒出现首领。前四关结束后从三张强化里选一张。
5. 被击落最多续战三次：重开当前关，保留强化，分数扣除 35%。演练不计入战役最高分。

航线：**晨曦海港 → 翡翠峡谷 → 冰川阵列 → 熔核工厂 → 天穹核心**。

## 操作

| 操作 | 键盘 | 指针 / 触屏 |
| --- | --- | --- |
| 移动 | WASD 或方向键 | 在战场按住拖动，战机按相对位移移动 |
| 精密低速 | 按住 Shift | 「精密移动」 |
| 震荡炸弹 | 空格 | 「震荡炸弹」 |
| 雷霆爆发 | E | 充满后点「雷霆爆发」 |
| 暂停 | P 或 Esc | 暂停按钮 |

切到后台或窗口失焦会暂停。中央小光点是受击核心。贴近子弹可以擦弹得分并充能。标准模式在最后一击且还有炸弹时会自动保命；街机模式弹幕更密，炸弹要自己按。

## 权限

| 权限 | 用途 |
| --- | --- |
| `ui.view` | 打开侧栏页面 |

侧栏会把脚本内联成普通脚本，不解析 `import`。`data.js`、`engine.js`、`airframes.js`、`render.js`、`audio.js`、`app.js` 仍是原作的 ES Modules，测试直接引用它们。`boot.js` 由 `node assemble.mjs` 按模块包进各自的函数，供页面运行，远小于宿主 8MB 的单文件上限。改了上述模块后要重新生成 `boot.js`。
