# 雷霆战机

侧栏里的竖版射击小游戏。战机在画面下方，敌机从上方编队压下来，打法接近经典的雷霆战机：走位、连射、接道具、打首领。

整局都在插件页面里运行，不联网，也不读工作区里的文件。

## 怎么玩

1. 打开侧栏「雷霆战机」，点「开始」。
2. 移动战机躲开子弹，击落敌机得分。默认自动射击，也可以关掉，改成自己开火。
3. 敌机会掉落道具：火力、射速、护盾、炸弹和额外生命。
4. 清完一波会加分，下一波更快、更密。每 5 波出现一架首领。
5. 被击中掉一条命，火力降低一档。命用完后可以重开。

最高分和「自动」开关记在插件自己的页面存储里，关掉再打开还在。

## 操作

| 操作 | 键盘 | 指针 / 触屏 |
| --- | --- | --- |
| 移动 | 方向键或 WASD | 在画面上按住拖动，战机跟在手指上方 |
| 射击 | 空格（按住） | 「射击」按钮；或打开「自动」 |
| 炸弹 | B | 「炸弹」按钮 |
| 暂停 | P | 「暂停」 |
| 开始 / 继续 | Enter，或未开局时空格 | 画面中央的按钮 |
| 重开 | — | 「重开」 |

先点一下画面，键盘才会送到游戏里。

## 规则

- 开局 3 条命，最多 5 条。护盾可以抵消一次撞击或子弹。
- 火力四档：单发、双发、三向、五向。已经满档时再吃到火力道具，改加分。
- 短时间连续击落会提高这一下的分数，最多 6 倍。挨打会打断连击。
- 炸弹清掉屏幕上的敌方子弹，普通敌机直接击落，首领掉一段血。最多存 3 枚。
- 清空当前波次有额外加分。

道具字母：W 火力，R 射速，S 护盾，B 炸弹，+ 生命。
