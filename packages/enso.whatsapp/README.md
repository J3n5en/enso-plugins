# WhatsApp

把 WhatsApp 当作 EnsoCode 秘书的一个联系方式。扫码登录后，主人发来的文字和图片交给秘书，秘书的回复、图片和文件再发回 WhatsApp。

## 版本要求

- 文字收发、秘书发图片和文件：EnsoCode 0.3.9 及以上（含 0.3.12 稳定版和 0.3.13 内测版）。
- 收图片：EnsoCode 0.3.13-beta.13 及以上的内测版，或之后的 0.3.13 正式版。更旧的版本只把图片的说明文字交给秘书；只发图片或附件、没有文字的私聊消息交不过去，插件会回一句升级提示。

## 风险

> ⚠️ 使用前请先读完这一段。

- 这里用的是 WhatsApp Web 多设备协议的**非官方实现**（[Baileys](https://github.com/WhiskeySockets/Baileys)），不是 WhatsApp 官方接口，可能违反 WhatsApp 服务条款。
- 扫码的号码**可能被限制或封号**。「自己号码」模式下风险更高，因为被封的是你的主号。
- **建议用副号**（默认模式）。
- 这个插件**还没有在真实号码上做过完整验证**：协议层只在不联网的条件下测过，收发、群聊、收图片、重连都靠模拟测试覆盖。WhatsApp 改协议时可能突然不能用。

## 登录

1. 在插件市场安装并启用「WhatsApp」。
2. 打开秘书的联系方式，展开「WhatsApp」卡片并打开开关，再选模式（默认副号），点「扫码登录」。
   - 有多个秘书时，每个秘书都能看到这张卡片，但同一时间只有一个秘书能打开它，消息只交给打开它的秘书；没有秘书打开时，收到的消息不处理、不回复。
   - 登录的号码、绑定的主人和群属于插件本身，不按秘书区分；换一个秘书打开，就由那个秘书接手同一个号。
3. 手机 WhatsApp → 设置 → 已关联的设备 → 关联新设备，扫描页面上的二维码。二维码会自动刷新，刷满 3 轮还没扫就停下，再点一次即可。

## 两种模式

**副号（默认）**：扫码的是一个专用副号。连上后设置页显示一个 6 位绑定码，用你的主号给副号发一条只含这 6 位数字的消息，发消息的号码就绑成主人。绑定码 10 分钟有效、只能用一次，猜错 5 次作废。之后只认主人的私聊；其他人的私聊不读、不回。

**自己号码**：扫码的是你自己的号。只认「给自己发消息」这个对话，秘书的回复也出现在这里；其他所有私聊不读、不回。这个模式下手机不会收到回复通知，用自己的号跑非官方协议被封的风险更高。

秘书发出的每条消息都先生成 id 记下（保留最近 500 条，存在插件数据目录），消息回到收件流时按 id 认出来跳过，不会把自己的回复当成新消息。

## 群聊

默认不读、不回任何群。要用的话：

1. 把副号（或自己号码模式下的你）拉进群。
2. 在设置页点「列出所在的群」，把要用的群打开。只有设置页里打开的群才生效，群里来了消息也不会自动绑定。
3. 在这个群里，只有两种消息会交给秘书：有人 @ 了这个号，或者有人回复了秘书发过的消息。其他群消息一律忽略。
4. 秘书的回复发回同一个群，并引用触发的那条消息。

群里任何成员都能这样触发回复，群消息会交给秘书，只启用你信任的群。群不进主动推送名单，里程碑、确认卡和审批不会发到群里。群成员发的 `/命令` 和「确认 N」会被忽略，只有主人本人可以。

## 消息

- 文字收发。秘书的 markdown 转成 WhatsApp 格式（`*粗体*` `_斜体_` `~删除线~` `` `代码` `` 和 ```` ``` ```` 代码块），超过 4000 字分条发送，代码块被切开时会补齐。
- 秘书可以发图片和文件（单个不超过 10MB，由 EnsoCode 限制）。上传走 `enso.net.fetch`，只发到清单里的媒体域名。发送失败时 EnsoCode 会另回一句说明和电脑上的路径。
- 收图片：只有通过上面过滤的消息（主人私聊、「给自己发消息」、已绑定群里 @ 或回复秘书）才下载，其余一律不下载。下载走 `enso.net.fetch`，只到清单里的媒体域名，30 秒超时，在插件里解密后交给 EnsoCode；格式、10MB 上限和保存由 EnsoCode 处理。图片说明当作文字；相册在 WhatsApp 里是一张一条，逐条交给秘书。以 png / jpeg / webp / gif 文件形式发的图片也会下载。
- 视频、语音、贴纸、其他文件，以及没下载下来的图片（超时、失败、超过 `enso.net.fetch` 的 5MB 响应上限），由 EnsoCode 统一回对方一句收不下，插件自己不回。群里收不下的附件不交给 EnsoCode，也不回提示；只有附件没有文字时整条忽略。
- 秘书处理时显示「正在输入」。
- 断线自动重连，2 秒起指数退避，最长 1 分钟；在手机上移除了这台设备时显示「需要重新扫码」，不再重连。

「退出登录」会通知 WhatsApp 移除这台设备，并清掉本机的登录状态、主人和群。

## 数据

登录凭据只存在插件数据目录的 `auth/`，不写日志、不进状态和报错文案；协议层的日志全部丢弃。主人、群、已发消息 id 存在 `state.json`。

## 权限

| 权限 | 用途 |
| --- | --- |
| `secretary.contact` | 注册「WhatsApp」联系方式，把消息交给秘书并发送回复 |
| `net.fetch` | 在 WhatsApp 媒体服务器（`mmg.whatsapp.net`、`*.cdn.whatsapp.net`）上传要发的图片和文件、下载收到的图片 |
| `process.background` | 常驻保持 WebSocket 连接 |
| `ui.view` | 扫码登录和设置页 |

清单里的 `web.whatsapp.com` 是协议的 WebSocket（`wss://web.whatsapp.com/ws/chat`）。EnsoCode 没有 WebSocket 权限，这条连接由插件进程直接建立，写在 `net.domains` 里是为了让连接去向在市场里可见。

## 开发

`vendor/baileys.mjs`、`vendor/THIRD_PARTY.md` 和 `LICENSE` 是打包产物，不要手改。更新 Baileys：

```bash
cd scripts/whatsapp && npm ci && node build.mjs
```

二维码在页面里本地生成，不访问外网。生成器是 Kazuhiko Arase 的 QR Code Generator（MIT），见 `lib/qrcode.js`。
