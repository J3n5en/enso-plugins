# Chat Board

跨项目的会话看板。每张卡片就是一个会话，不是任务便笺。用来同时照看各个项目里的会话：谁在跑、谁在等你、哪里还没看。

这和 `enso.kanban` 不是一块板。Kanban 是某个项目内部、由人和会话共同维护的任务卡片；这里的卡片来自会话列表本身，不能当成待办事项创建。

## 使用

1. 打开侧栏「会话看板」。看板覆盖所有项目里还在的主会话（最多 200 个，不含 Bot、不含已结束的会话）。
2. 默认四列：**待处理**、**进行中**、**等你处理**、**已完成**。列可以改名、调顺序、折叠、新增和删除。删列时，里面的卡片会挪到相邻的列。
3. 会话第一次出现时按它现在的状态落列：正在跑的进「进行中」，等你回答或出错的进「等你处理」，已归档的进「已完成」，其余进「待处理」。
4. 拖动卡片换列或调整顺序。拖过去之后卡片会固定在那一列，不再跟着状态跑。卡片上的「固定」可以取消。
5. 点卡片切换到那个会话。拖动不会触发切换。
6. 给卡片写备注，方便下次接着看。备注只存在这块看板里，不会写进会话。
7. 用标题、备注、项目筛选，也可以只看未读、进行中、等你处理或已结束。
8. 「新建会话」会在当前项目里开一个会话，可选地把一段文字放进新会话的输入框，由你确认后再发送。

状态点是会话连同它的 coworker、子会话汇总出来的，和侧栏圆点一致：进行中、等你处理（有提问或审批）、出错、空闲。插件接口只列出主会话，coworker 不会单独成卡；点开主会话就能看到它的 coworker 标签。

### 未读

会话从「进行中」停下来，而你当时不在这个会话里，卡片会铺上黄色并打一个点，所在列的标题旁也会有点。再次开始运行，或你点开这张卡片之后，标记消失。

### 已结束

会话从列表里消失（结束或删除）后，卡片留在原来的列里，备注还在，标成「已结束」。可以单张移除，也可以一次清除全部已结束卡片。默认先藏起来，用筛选「已结束」再看。

## 行为开关

点标题栏的齿轮：

| 开关 | 默认 | 作用 |
| --- | --- | --- |
| 跟随状态归列 | 开 | 没固定的卡片会按运行、等待、归档换到对应的列 |
| 待处理的会话一开始运行就移到进行中 | 开 | 即使关了跟随状态，或这张卡片已固定，只要它还在「待处理」并且刚刚开始运行，就移到「进行中」 |
| 显示项目 / 备注 / 时间 | 开 | 只影响这块面板 |
| 隐藏空闲的已归档会话 | 开 | 已归档、空闲、且没有未读的会话先不占格子 |
| 隐藏已结束 | 开 | 已结束的卡片默认不显示 |

跟随状态和「移出待处理」保存在插件数据目录的 `board.json`。显示开关和筛选保存在面板自己的存储里。

每块看板最多 20 列。连同已结束的卡片最多保留 500 张；超出时先丢掉没有备注的已结束卡片。

## 限制

`session.focus` 只能切换到**当前项目**里的会话。其他项目的卡片可以看状态、写备注、拖动分列；点开会提示它所在的项目，不会假装已经跳过去。新建会话也开在当前项目。

 coworker 和子代理没有单独的列表接口，所以不会各占一张卡片。它们的运行、提问和审批算在所属主会话的状态里。

## 权限

| 权限 | 用途 |
| --- | --- |
| `ui.view` | 打开侧栏页面 |
| `session.readAll` | 列出所有项目的主会话 |
| `session.focus` | 点卡片时切换到当前项目里的会话 |
| `session.create` | 从看板新建会话 |
