# Agent Inbox

侧栏里的一份跨会话、跨项目收件箱。把正在等你处理的事按项目收在一起：未读数、点一下切回当前项目里的那个会话。

它不是某个会话底部的审批条，也不是 Bot 的收件箱。审批仍然在会话自己的审批条里做；这里只负责告诉你「谁在等你」，然后把你带过去。

需要 EnsoCode 0.3.2 及以上。插件常驻，这样会话状态变化时不会因为进程没开着而丢掉。

界面参考了 [Orca Agent Inbox](https://github.com/felix-lj-ct/orca-agent-inbox) 的分组和未读，数据全部来自 Enso 已经提供的宿主接口。

## 使用

1. 安装并启用后，右侧栏打开「收件箱」。输入框底栏在有事项时显示「N 在等你」，点一下也会打开这个页面。
2. 条目按项目分组。当前项目排在最前，标成「当前项目」。
3. 点当前项目里的一条，会切到那个主会话，并把这一条标成已读。
4. 顶部分类可以只看审批、提问或失败，也可以只看未读。点「全部标为已读」不会让事项消失，只是清掉未读点。
5. 事项还在，是因为对应的审批、提问或失败状态还在。数量变了，或者失败文本变了，会重新变成未读。

未读记在插件数据目录的 `seen.json`。侧栏上的筛选记在页面状态里。

## 收进来的事项

| 类型 | 宿主依据 | 卡片上能看到的 |
| --- | --- | --- |
| 审批 | `session.status` / `session_status` 的 `pendingApprovals` | 这个主会话（含子会话）有几项工具调用在等审批 |
| 提问 | 同上的 `pendingAsks` | 有几个提问在等你回答 |
| 失败 | 汇总状态 `error`：主会话上一轮失败，或工作进程退出 | 固定标题「上一轮失败」。如果当时收到过 `tool_result` 且 `isError` 为真，附上最近一次的工具名和截断后的错误文本 |

列表来自 `enso.session.list({ scope: 'all' })`：所有在用项目的主会话，按最近活动排序，最多 200 条。不含 Bot 会话，不含已经结束的会话。启用后会拉一次全量，之后靠 `session_status` 更新；每 60 秒再对一次账，并在 `session_end` 时去掉结束的主会话。子会话结束不会把主会话从列表里删掉。

点当前项目的会话时调用 `enso.session.focus`。子会话上的审批和提问会计入所属主会话，点击也是聚焦这个主会话。

## 做不到的事

这些宿主没有提供，插件不会编造：

- **过期凭据、OAuth 刷新失败、能力询问**（界面里的 `pendingCapabilityAsks`）都没有插件事件，也不会出现在 `pendingAsks` / `pendingApprovals` 里。
- **审批和提问的正文**拿不到。没有工具名、参数、命令或提问原文，所以这里不能代替会话里的审批条，也不能在收件箱里直接同意或回答。
- **还在继续的工具错误**不算「在等你」。`tool_result.isError` 只在主会话已经处于 `error` 时拿来补充失败卡片；回合没失败、agent 还在跑，就不会单开一条。附上的文本是最近一次观察到的工具错误，不保证就是这次失败的原因。插件没在跑时错过的 `tool_result` 补不回来，卡片就只写「宿主没有附带原因」。
- **别的项目切不过去。** `session.focus` 只能切到发起操作的这个项目里的会话，别的项目会返回找不到。那些条目仍会列出，点了只会标已读并说明要先打开那个项目。
- **Bot 会话**不在 `session.list` 里，也不发这些事件。Bot 自己的收件箱不受影响。

## 权限

| 权限 | 用途 |
| --- | --- |
| `ui.view` | 侧栏页面，以及把更新推给已打开的页面 |
| `agent.observe` | 接收 `session_status`、`tool_result`、`session_end` |
| `process.background` | 常驻，并每 60 秒对一次会话列表 |
| `session.readAll` | 列出所有项目的主会话，并读取它们的审批数、提问数和状态 |
| `session.focus` | 在你点击时切到当前项目的会话 |
