# 任务启动

从 GitHub issue 启动一个 Enso 会话。侧栏列出当前项目 `origin` 的 issue，选一个提示词模板，把替换后的提示词填进新会话并聚焦过去。需要的话，会先在**当前检出**上创建并切换分支。

这是 `enso.github` 的补充：那边看 issue、评论和 Actions，这边负责把一条 issue 变成一次会话。两边互不修改，登录状态也不共用。

需要 EnsoCode 0.2.14 及以上。启动会话只能从侧栏点击，宿主要求这次调用带有用户手势。

## 登录

按下面的顺序找凭据，找到即用：

1. 侧栏里的设备码登录。点「登录」后打开 GitHub 授权页，输入页面上的代码。授权范围是 `repo`，这样私有仓库的 issue 也能列出来。插件本身只读 issue，不会替你评论或改状态。设备码用的是公开 client id（与 GitHub 插件相同的 OAuth 应用），令牌写在本插件自己的数据目录。
2. 设置 → 插件 → 任务启动 里的 Personal Access Token。能读目标仓库的 issue 即可。
3. 环境变量 `GH_TOKEN` 或 `GITHUB_TOKEN`。
4. 已登录的 gh CLI（`gh auth token`）。

设备码登录的 token 在 `auth.json`，可在侧栏退出。

## 使用

1. 打开一个项目，再打开侧栏「任务启动」。仓库默认是当前项目 git `origin` 指向的 GitHub 仓库，也可以改成别的 `owner/name`。
2. 编辑提示词模板。模板在仓库之间共用，每个仓库记住自己选中的哪一个。最多 20 个，每个最长 8000 字。
3. 在打开、关闭、全部之间切换。列表按更新时间排序，最多 50 条，不含 Pull Request。筛选只作用于这 50 条。
4. 点一条 issue 看替换后的提示词，再点「启动」或「启动会话」。

新会话和当前项目的其他会话共用同一个检出。`session.create` 只会把提示词放进输入框，**不会自动发送**，聚焦过去之后需要你确认。

## 模板变量

| 变量 | 替换成 |
| --- | --- |
| `{{issue_url}}` | issue 链接 |
| `{{issue_number}}` | 编号 |
| `{{issue_title}}` | 标题 |
| `{{issue_body}}` | 正文。整段提示词超过约 32KB 时从正文截断 |
| `{{repo}}` | `owner/name` |
| `{{branch}}` | 启动后会话所在的分支；游离 HEAD 时是「（游离 HEAD）」 |

未知的 `{{name}}` 会原样留下。

## 分支，以及为什么没有 worktree

勾选「先创建并切换分支」时：

- 分支名由编号和标题生成，例如 `issue/40-fix-the-date-picker`。标题里没有可用的英文或数字时，名字就是 `issue/40`。
- 从**当前 HEAD** 创建，不 fetch、不推远程。
- 工作区必须干净（含未跟踪文件）。有未提交改动就取消这次启动，检出保持原样。
- 同名分支已存在时切换过去，不另起一个名字。已经在这个分支上时，即使工作区不干净也不会再切换。
- 使用 `git switch`（Git 2.23+）。分支名固定以 `issue/` 开头，不会被当成选项。

不创建 git worktree。Enso 的 `session.create` 只能在发起调用的那个项目里开会话，不能指定另一个目录。建一个旁边的 worktree 再开会话，会话仍停在原来的检出上，看起来像启动成功，实际改错地方。所以这里只提供「当前检出上的分支 + 新会话」。新会话和同一项目里的其他会话共用这个工作区；并行任务请用 Enso 自己的 worktree 隔离，而不是这个插件。

## Agent 工具

| 工具 | 作用 |
| --- | --- |
| `task_list` | 列出 issue（不含 PR） |
| `task_preview` | 渲染提示词，并说明如果要建分支会不会被未提交改动拦住 |

这两个工具都不会新建会话、分支或 worktree。要启动，用侧栏。

`repo` 不填时使用当前项目的 `origin`。

## 权限

| 权限 | 用途 |
| --- | --- |
| `agent.tool` | 提供上面的只读工具 |
| `net.fetch` | 访问 `github.com`（设备码登录）和 `api.github.com`（列 issue、读单条 issue） |
| `ui.view` | 打开侧栏 |
| `ui.openExternal` | 打开授权页和 issue 网页 |
| `session.create` | 在当前项目新建会话，并把提示词放进输入框 |
| `session.focus` | 聚焦到刚创建的会话 |

分支操作使用项目里的 git，不经过 `enso.fs`，也不会改仓库里的文件。模板和登录信息在插件数据目录。
