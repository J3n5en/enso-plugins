# Sage Focus（鼠尾草·专注）主题插件

独立、纯静态的 Enso 主题插件，使用当前主题插件机制，不需要新增内置主题或修改宿主源码。低饱和暖灰绿配色用于深色模式；浅色模式沿用默认 Enso。

## 安装

1. 在 Enso「设置 → Enso 插件」中选择从目录安装。
2. 选择本目录 `packages/enso.example.sagefocus`，即包含 `enso-plugin.json` 的目录，不要选 `themes` 子目录。
3. 确认 CSS 所需的「修改界面样式」授权，安装并启用插件。
4. 在「设置 → 外观」选择 **Sage Focus · 鼠尾草·专注（仅深色模式）**，切换到 **深色**，强调色设为 **跟随主题**。

插件 id：`enso.example.sagefocus`。主题键：`enso.example.sagefocus/sage-focus`。版本：`1.0.3`。

插件图标为 `assets/icon.svg`：暖灰绿底色、鼠尾草叶片与对焦框，无外部资源依赖。

启用插件不等于选中主题。本插件可以与豆沙绿插件并存，不用卸载豆沙绿。修改本目录后需重新安装或更新插件，已安装副本不会自动同步。

## 覆盖范围

- 主界面、侧栏、聊天区、输入框、顶栏和设置页的语义配色。
- 使用现有令牌的菜单、卡片、工具状态提示及浮层。
- 现有侧面板标签的悬停与活动状态、普通文本选区、输入光标和焦点轮廓。
- 聊天代码块背景及 14px / 1.6 排版；代码 token 颜色保留应用原有高亮。

## 明确不包含

现有插件接口不能完整替换编辑器的 Shiki/TextMate 主题、Shadow DOM 内选区/光标/诊断与 Diff 的全部颜色，也不能设置 xterm ANSI 配色。因此这些部分保持宿主原样，不用 CSS 强行统一所有代码文字，不修改终端偏好，不新增 JavaScript、依赖或宿主接口。

系统窗口控件、原生菜单、插件 iframe 和网页内容不保证跟随。文件树图标保留原有类型色。本插件不提供新的补全、语义分析或诊断功能。

弱文字没有使用对比度更低的 `#718578`，该颜色仅作滚动条悬停色。状态栏使用主文字提高可读性，不代表已完成全应用 WCAG 审计，也不作医学护眼承诺。

CSS 仅在本插件被选中且为深色模式时生效，切换主题即退出。背景图、自定义 CSS 和强调色预设可能改变最终效果；区域实色会遮住该区域的背景图。
