# 会话轨迹

在侧栏查看一次 Enso 会话里每一轮发生了什么：用户提示、模型请求、工具调用、子代理、token、缓存命中和耗时。

这和「上下文」不是同一件事。上下文看的是当前窗口里各类内容占了多少；轨迹看的是这一次会话按时间展开的调用过程。

## 使用

打开侧栏「轨迹」。默认是当前会话，顶部可以换成同一项目里的其他会话。会话还在跑时右上角显示状态，大约每 2 秒刷新；进行中的轮次会先出现，等记录写到磁盘后再补全 token 和全文。

点开一行可以看到提示词、工具参数、工具输出和思考摘要。子代理如果已经记下独立会话，展开后能看到它自己的轮次。

## 数据从哪来

读取的是 Enso 自己的会话记录，不是 Claude Code 的 `~/.claude/projects`。

- 会话文件是 pi session v3 的 jsonl，在应用数据目录的 `agent/sessions/`。
- 哪个会话对应哪个文件，以 `agent/source-registry.json` 里的 `sessionFile` 为准。
- 只沿当前叶子的 `parentId` 往回走，分叉出去又放弃的内容不会混进来。
- 子代理和 coworker 的文件名在 `agent/sessions/child-runs/<会话 id>.jsonl`。
- 还没写盘的这一轮，用 `input`、`tool_call`、`tool_result`、`agent_start`、`agent_end`、`context_usage`、`session_status` 这些会话事件补上。

缓存命中率 = 缓存读取 /（未缓存输入 + 缓存读取 + 缓存写入），和上下文面板用的是同一种算法，这里按整段会话合计，每一条模型请求也可以单独看。

很大的会话文件只读末尾约 12MB。单段正文在界面里截到 1.2 万字。

## 权限

| 权限 | 用途 |
| --- | --- |
| `ui.view` | 打开侧栏页面 |
| `agent.observe` | 接收当前轮次的输入、工具、模型和上下文事件 |
| `session.read` | 列出本项目的会话并读取运行状态 |
