# Beads

当前项目的 Beads 任务板。列是就绪、进行中、阻塞和已关闭；也可以换成表格。点开一条任务能看到依赖和评论，可以认领、关闭、重新打开，或把任务交给一个新的 Enso 会话。

数据留在项目里。装了 `bd` 时，读写都走 `bd`。没有 `bd`、但有 `.beads/issues.jsonl` 时，直接读写这个文件。没有初始化过 Beads 时，侧栏只显示说明，不会假装已经有一块空看板。

## 使用

1. 在项目根目录初始化：`bd init`。不需要云服务。
2. 打开侧栏「Beads」。右上角可以在看板和表格之间切换，也可以按标题、编号、负责人或标签搜索。
3. 点一条任务查看描述、依赖和评论。认领会把状态改成进行中；关闭可以写原因。
4. 「交给新会话」会新建一个 Enso 会话，把任务说明放进输入框，并切换过去。这一步不会认领或关闭任务。

有暂缓或其他状态的任务时，看板会多出对应的列。

## 权限

| 权限 | 用途 |
| --- | --- |
| `ui.view` | 打开侧栏页面 |
| `fs.read` | 读取项目里的 `.beads` |
| `fs.write` | 在没有 `bd` 时把认领、关闭和评论写回 `issues.jsonl` |
| `session.create` | 把任务交给一个新会话 |
| `session.focus` | 切换到这个会话 |

命令行可执行文件可以用环境变量 `BD_BIN` 指定。
