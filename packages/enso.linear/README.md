# Linear

在侧栏查看 Linear 议题：指派给我的、当前周期、团队待办和分拣。当前 git 分支如果能对上议题标识（例如 `pat/eng-142-fix-sync`），那条议题会钉在列表顶部并高亮。打开议题可以改状态、优先级和负责人，查看子议题、链接和评论，也可以在一个新的 Enso 会话里开始处理。

需要 EnsoCode 0.2.14 及以上。插件和 Linear 没有隶属关系。

## 连接

Enso 没有内置的 Linear 账号。任选一种方式，找到即用：

1. **Personal API Key（推荐）**。在 Linear 打开 设置 → 账户 → 安全与访问 → Personal API keys，新建一把带读写权限的钥匙。再在 Enso 的 设置 → 插件 → Linear 里粘贴到 Personal API Key。这是密钥字段，只存在宿主的配置里。
2. **环境变量** `LINEAR_API_KEY`。没有填写上面的钥匙、也没有 OAuth 登录时才会用到。
3. **OAuth（PKCE，可选）**。在 Linear 自建一个 OAuth 应用，把回调地址设成 `http://127.0.0.1:47321/callback`，权限选 `read` 和 `write`。只把 **Client ID** 填进插件设置。不要填写 Client Secret，插件也不会发送它。侧栏点「使用 OAuth 登录」后，本机只在 `127.0.0.1:47321` 上等这一次回调；如果端口被占用，把浏览器地址栏里的完整回调地址粘贴回侧栏即可。访问令牌大约 24 小时有效，刷新令牌由插件换新并写回数据目录的 `auth.json`（文件权限 `0600`）。

OAuth 登录成功后优先使用这套令牌，直到在侧栏退出。退出时会请求 Linear 撤销令牌并删除本地文件。API Key 不会因此被撤销，到设置里清空即可。

令牌和 API Key 不会写进日志，也不会出现在面板或工具返回值里。

## 使用

1. 打开侧栏「Linear」。
2. 用「我的 / 周期 / 待办 / 分拣」切换。我的议题按进行中、评审中、待处理、待办、分拣分组，紧急的排在前面；最近 14 天完成或取消的议题收在底部。
3. 选一个团队可以缩小范围。周期、待办和分拣需要选定团队。当前周期会显示进度和剩余天数。
4. 筛选框即时过滤当前列表。在里面按回车，会到 Linear 里做全文搜索。
5. 点开一条议题可以改状态下拉、优先级和负责人，阅读描述、子议题、关联和附件，以及评论。链接只在点击后用浏览器打开。
6. 「在会话中开始」会新建一个 Enso 会话，提示里包含议题标识、标题、描述和建议分支。如果当前分支已经对上这个议题，提示会让会话留在该分支上。「插入输入框」则把同一段提示放进当前输入框。

快捷键：`1`–`4` 切换视图，`/` 聚焦筛选，回车搜索，`r` 刷新，`Esc` 从详情返回，`o` 在浏览器打开当前议题。

## Agent 工具

| 工具 | 作用 |
| --- | --- |
| `linear_list` | 列出我的、周期、待办或分拣议题 |
| `linear_search` | 全文搜索 |
| `linear_view` | 查看一条议题及其子议题、链接和评论 |
| `linear_comment` | 发表评论 |
| `linear_update` | 修改状态、优先级或负责人 |
| `linear_start` | 新建 Enso 会话并开始处理这条议题 |

`id` 可以是 `ENG-123` 或 UUID。

## 权限

| 权限 | 用途 |
| --- | --- |
| `agent.tool` | 提供上面的 Agent 工具 |
| `net.fetch` | 只访问 `api.linear.app`（GraphQL、OAuth 令牌与撤销） |
| `ui.view` | 打开侧栏页面 |
| `ui.openExternal` | 打开 Linear 授权页和议题网页 |
| `session.create` | 新建会话并开始处理议题 |
| `composer.draft` | 把开始处理的提示插入输入框 |

授权页在 `linear.app`，由系统浏览器打开，插件自己不请求这个域名。
