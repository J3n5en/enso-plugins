# Telegram

用 Telegram Bot 远程使用 EnsoCode 会话。在右侧「Telegram」面板粘贴 Bot Token 一键连接，然后把私聊、群聊、甚至论坛群里的单个话题，分别绑定给任意 EnsoCode 会话（包括跨项目会话与秘书会话）。

## 连接

1. 在 Telegram 找 `@BotFather`，发 `/newbot` 创建机器人，复制 Token。
2. 打开 EnsoCode 右侧「Telegram」面板，粘贴 Token，点「校验并连接」。
3. 想在群里用上下文/免 @ 直发：对 `@BotFather` 发 `/setprivacy` 选 **Disable**，再把机器人移出群重新拉进来。

> 旧版 EnsoCode 不支持从面板保存 Token 时，面板会提示你去「设置 → 插件 → Telegram」填写。

## 绑定与路由

- 面板点「＋ 配对绑定」生成配对码：私聊里发 `/bind 123456`（或点绑定链接），群/话题里发 `/bind@你的机器人 123456`——**在话题里发出即绑定该话题**，在群聊主界面发出即绑定整群兜底。不用了就点配对卡片右上角的「取消 ×」，配对码立刻作废。
- 面板还会列出机器人「见过的」群与话题，可直接一键绑定，无需配对码。
- 每条路由都能独立选择目标会话（秘书 / 各项目分组），支持多条路由绑定同一会话，也支持一个论坛群的不同话题各绑不同会话。
- 点路由卡片上的会话名（或展开后「目标会话」旁的「跳转 ↗」）直接切到那个会话。会话在别的项目时，旧版 EnsoCode 跳不过去，面板会提示先打开那个项目或升级。
- 「目标会话」旁的「绑定当前」把这条路由一键改绑到主界面正在打开的会话，以点击那一刻的会话为准。没有打开会话或已经绑在当前会话时按钮置灰，悬停可看原因。
- 路由卡片最左边是开关：关掉即暂时静音，不用解绑。静音期间机器人不响应这条路由的任何消息、命令和按钮，也不记群聊上下文。回复、进度、同步镜像和提问卡片都不再发过去，还没投出去的攒批消息直接丢弃。Agent 用 `telegram_reply` / `telegram_send_media` 广播时会跳过它，显式指定这条路由时会报「该路由已暂停（静音）」。打开开关即恢复。

## 管理员与普通用户

- **管理员（可信）**：消息作为可信指令直接交给会话；只有管理员能用 `/steer` `/stop` `/session` `/sync` `/context` `/allow` `/deny` `/admin` `/unadmin` `/unbind`、切换会话按钮、提问卡片的按钮与回复作答，也只有管理员能改绑已绑定的聊天。
- **普通用户（不可信）**：白名单成员与私聊绑定的其他人。可以正常发消息，但消息由 EnsoCode 按外部数据包裹，只能用 `/status` `/help` `/id`。
- 首位用配对码绑定的人自动成为管理员；匿名管理员认不出是谁，不能成为管理员。之后在「权限」页添加或移除，或在群里回复某人的消息发 `/admin`、`/unadmin`。
- 群聊上下文里其他成员的消息始终标为第三方内容，即使由管理员触发也不会被当作指令。管理员和普通用户的消息在攒批时分开缓冲，绝不合并进同一条可信投递。
- 从 1.0 升级时管理员名单为空，已有白名单成员不会自动升为管理员，请在「权限」页设置。

## 白名单与触发

- 全局白名单在「权限」页按 Telegram User ID 管理（对机器人发 `/id` 可以查到）；群内有人触发被拦时会留下待批准请求，可批准为普通用户或管理员。
- 每条群/话题路由三种白名单模式：**继承全局**（默认）、**本路由独立**、**全群开放**。
- 群聊里默认需要 `@机器人` 或回复机器人的消息才触发；打开路由的「免 @ 直发」后，满足白名单的成员直接发消息即可。
- 私聊默认放行。

## 每条路由的高级配置

- **上下文 X 条**：触发时附带该路由最近 X 条未投递的其他消息（话题之间严格隔离）。
- **攒批安静期**：连发多条消息在安静期结束后合并成一条投递。
- **最小触发间隔**：限制该路由触发频率，间隔内的消息合并缓冲，到期统一投递。`/steer`、`/stop` 等控制指令不受限速影响。
- **提示词前置**：每次从该路由注入时拼在消息顶部的专属角色/规则说明（最多 2000 字）。
- **进度提示**（默认开）：关掉后不再发「⏳ 已收到，处理中…」「↪️ 已插入当前任务」「▶️ 会话已启动…」「📥 已收到，将在安静期结束后合并处理…」、工具步骤进度和「🤫 本轮已在别处静默处理。」，只发最终回复。「正在输入」状态、排队提示和出错提示照常。`/status` 会显示这个开关。

## 图片

- 入站：单图与多图相册都支持（相册合并为一次注入）；超过 5MB 的会跳过并附说明，不丢整组。
- 出站：Agent 可调用 `telegram_send_media` 发送 1–10 张本地图片（自动合成相册、GIF 单独发送、超 10 张分块），`telegram_reply` 发文本；两者都可加 `target` 指定路由。

## ask_user 按钮

会话里 Agent 提问时，绑定的路由会收到带按钮的提问卡片：点按钮直接作答（★ 为推荐项），或回复卡片消息输入自定义答案。在桌面端或其他路由作答后，卡片会原位更新并清掉按钮。

## 群内命令

`/help` `/status` `/id` `/session` `/steer` `/stop` `/sync` `/allow` `/deny` `/admin` `/unadmin` `/context` `/bind` `/unbind` —— 回发都会正确落到对应话题。

## 权限

| 权限 | 用途 |
| --- | --- |
| `agent.inject` | 把 Telegram 消息投递到绑定的会话 |
| `agent.injectTrusted` | 仅用于管理员的消息：不带 sender 以可信方式投递，模型直接按指令执行。普通用户的消息仍带 sender、由宿主按外部数据包裹。宿主不接受可信投递时自动降级为外部消息并在聊天里提示一次。升级时宿主会提示确认此权限。 |
| `session.focus` | 在面板里点目标会话时切换过去 |

## 迁移

从 0.4.0 升级时，旧的绑定、排队消息与上下文自动迁移为按路由存储，不会丢绑定。从 1.0 升级只新增空的管理员名单。
