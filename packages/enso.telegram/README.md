# Telegram Bot

用 Telegram Bot 远程使用 EnsoCode 会话。在右侧「Telegram Bot」面板粘贴 Bot Token 一键连接，然后把私聊、群聊、甚至论坛群里的单个话题，分别绑定给任意 EnsoCode 会话（包括跨项目会话与秘书会话）。

## 连接

1. 在 Telegram 找 `@BotFather`，发 `/newbot` 创建机器人，复制 Token。
2. 打开 EnsoCode 右侧「Telegram Bot」面板，粘贴 Token，点「校验并连接」。
3. 想在群里用上下文/免 @ 直发：对 `@BotFather` 发 `/setprivacy` 选 **Disable**，再把机器人移出群重新拉进来。

> 旧版 EnsoCode 不支持从面板保存 Token 时，面板会提示你去「设置 → 插件 → Telegram Bot」填写。

## 绑定与路由

- 面板点「＋ 配对绑定」生成配对码：私聊里发 `/bind 123456`（或点绑定链接），群/话题里发 `/bind@你的机器人 123456`——**在话题里发出即绑定该话题**，在群聊主界面发出即绑定整群兜底。不用了就点配对卡片右上角的「取消 ×」，配对码立刻作废。
- 面板还会列出机器人「见过的」群与话题，可直接一键绑定，无需配对码。
- 每条路由都能独立选择目标会话（秘书 / 各项目分组），支持多条路由绑定同一会话，也支持一个论坛群的不同话题各绑不同会话。
- 点路由卡片上的会话名（或展开后「目标会话」旁的「跳转 ↗」）直接切到那个会话。会话在别的项目时，旧版 EnsoCode 跳不过去，面板会提示先打开那个项目或升级。
- 「目标会话」旁的「绑定当前」把这条路由一键改绑到主界面正在打开的会话，以点击那一刻的会话为准。没有打开会话或已经绑在当前会话时按钮置灰，悬停可看原因。
- 路由卡片最左边是开关：关掉即暂时静音，不用解绑。静音期间机器人不响应这条路由的任何消息、命令和按钮，也不记群聊上下文。回复、进度、同步镜像和提问卡片都不再发过去，还没投出去的攒批消息直接丢弃。Agent 用 `telegram_reply` / `telegram_send_media` 广播时会跳过它，显式指定这条路由时会报「该路由已暂停（静音）」。打开开关即恢复。

## 管理员与普通用户

- **管理员（可信）**：消息作为可信指令直接交给会话；只有管理员能用 `/steer` `/stop` `/session` `/sync` `/context` `/allow` `/deny` `/admin` `/unadmin` `/unbind`、切换会话按钮、提问卡片的按钮与回复作答，也只有管理员能改绑已绑定的聊天。
- **普通用户（不可信）**：白名单成员与私聊绑定的其他人。可以正常发消息，但消息由 EnsoCode 按外部数据包裹，只能用 `/status` `/help` `/id`。
- 首位用配对码绑定的人自动成为管理员；匿名管理员认不出是谁，不能成为管理员。之后在「权限」页添加或移除，或在群里回复某人的消息发 `/admin`、`/unadmin`。
- 群聊上下文里其他成员的消息始终标为第三方内容，即使由管理员触发也不会被当作指令。管理员和普通用户的消息在攒批时分开缓冲，绝不合并进同一条可信投递。
- 从 1.0 升级时管理员名单为空，已有白名单成员不会自动升为管理员，请在「权限」页设置。

## 匿名管理员与频道身份

群里开了「匿名管理员」或「以频道身份发言」时，Telegram 只告诉机器人一个占位账号（`GroupAnonymousBot`、`Channel_Bot`），不给真实 User ID。插件这样处理：

- **匿名管理员**：先读本群管理员列表（`getChatAdministrators`，缓存 10 分钟，群成员变动时作废），从开了匿名的管理员里认人。
  - 只有一位开了匿名：就是 TA，按 TA 本人处理（是插件管理员就可信，否则按普通用户）。消息带了头衔但和 TA 的头衔对不上时视为认不出。
  - 有多位：消息头衔（`author_signature`）唯一对上某位的自定义头衔时按那位处理，否则认不出。
  - 读不到管理员列表（机器人没权限、网络失败）：认不出。
  - 认不出时看路由开关「信任本群匿名管理员」（默认关）。关着按普通用户处理，机器人在群里提示一次原因和解决办法（每群每小时最多一次）；打开则按管理员处理。风险：打开后群里任何开了匿名的管理员在认不出时都会被当成你。私聊不受影响。
- **以频道身份发言**：不会推断成任何人。频道在「权限」页的「可信发言频道」名单里时按管理员处理（默认空，可从最近见到的频道一键加入）；机器人读得到该频道管理员且频道主是插件管理员时，候选旁会标「这是你的频道」，仍需手动加入，因为频道的其他管理员也能以它发言。不在名单里按普通用户处理，同样每群每小时提示一次。
- **链接频道自动转发**进讨论群的帖子不触发机器人、不当指令；开了上下文时作为群聊上下文记下。
- 白名单：认出是谁的匿名管理员按 TA 本人过滤；认不出的匿名管理员（总归是本群管理员）和频道身份不按白名单过滤。
- 注入头里的称呼分别是「群匿名管理员」、「@名字（匿名发言）」和「频道身份「频道名」」，不再显示占位账号名。
- 借开关或频道名单获得的信任只管发指令：不能用 `/admin`、`/unadmin` 改管理员名单。配对 `/bind` 只认真实账号，匿名或频道身份发配对码会被拒绝，要先切回个人身份。提问卡片的按钮带的是点按人的真实账号，不受匿名影响。

## 白名单与触发

- 全局白名单在「权限」页按 Telegram User ID 管理（对机器人发 `/id` 可以查到）；群内有人触发被拦时会留下待批准请求，可批准为普通用户或管理员。
- 每条群/话题路由三种白名单模式：**继承全局**（默认）、**本路由独立**、**全群开放**。
- 群聊里默认需要 `@机器人` 或回复机器人的消息才触发；打开路由的「免 @ 直发」后，满足白名单的成员直接发消息即可。
- 私聊默认放行。

## 上一条还没回复完又来了新消息

同一个会话一次只处理一轮 Telegram 发来的任务。上一轮还没结束时：

- 普通消息先排队，机器人引用这条消息回一句「⏸ 已排队：前面还有 N 条没处理完」（关了进度提示也会发）。上一轮回复发出后，排在最前的那条才交给会话，它的排队提示改成「▶️ 轮到这条了」，最终回复写进这里。关了进度提示时，最终回复另发一条并引用原消息。每条消息都拿到自己的回复，不会把上一条的回复当成这一条的。
- `/steer` 不排队，直接插进正在跑的任务，机器人回「↪️ 已插入当前任务」。这一轮的回复仍然发给最初触发它的那条消息。
- `/stop` 停掉当前这一轮，它的占位改成「⏹ 已停止」，排队的下一条接着处理。
- 每个会话最多排 10 条，再来的消息会被明确告知没排上，不会悄悄挤掉前面的。
- 上一轮始终等不到回复（会话出错停了、EnsoCode 中途重启等）时，会话空闲 15 秒后，机器人告诉那条消息「⚠️ 这一轮没有等到回复，请重新发送」，再接着处理排队的消息。旧版 EnsoCode 查不到会话状态，要 20 分钟没有任何动静才这样处理。
- 绑定到不同会话的聊天和话题各排各的队，互不影响。

## 每条路由的高级配置

- **上下文 X 条**：触发时附带该路由最近 X 条未投递的其他消息（话题之间严格隔离）。
- **攒批安静期**：连发多条消息在安静期结束后合并成一条投递。
- **最小触发间隔**：限制该路由触发频率，间隔内的消息合并缓冲，到期统一投递。`/steer`、`/stop` 等控制指令不受限速影响。
- **提示词前置**：每次从该路由注入时拼在消息顶部的专属角色/规则说明（最多 2000 字）。
- **进度提示**（默认开）：关掉后不再发「⏳ 已收到，处理中…」「↪️ 已插入当前任务」「▶️ 轮到这条了…」「📥 已收到，将在安静期结束后合并处理…」、工具步骤进度和「🤫 本轮已在别处静默处理。」，「正在输入」状态也一并隐藏（进行中的轮次关掉后立即停止），只发最终回复。排队提示和出错提示照常。`/status` 会显示这个开关。
- **回复时引用原消息**（默认开，私聊和群聊都开）：机器人的最终回复用 Telegram 的「回复」样式引用触发这轮的那条消息。攒批合并多条时引用最后一条，话题里照旧发在原话题，长回复分段时只有第一段引用。占位消息发出时就带引用，之后被改写成回复也保留引用；提问卡片和「⏸ 已排队」提示同样引用。原消息已被删除或引用不了时照常发送，只是不带引用。关掉后上述消息都直接发送。从 1.1 升级的路由按开处理，`/status` 会显示这个开关。

## 图片

- 入站：单图与多图相册都支持（相册合并为一次注入）；超过 5MB 的会跳过并附说明，不丢整组。
- 出站：Agent 可调用 `telegram_send_media` 发送 1–10 张本地图片（自动合成相册、GIF 单独发送、超 10 张分块），`telegram_reply` 发文本；两者都可加 `target` 指定路由，加 `replyTo`（消息 id）引用某条消息。注入给会话的每条消息头里都带 `target=…` 和 `message_id=…`。本会话绑定了多个聊天时，`replyTo` 必须和 `target` 一起用。

## ask_user 按钮

会话里 Agent 提问时，绑定的路由会收到带按钮的提问卡片：点按钮直接作答（★ 为推荐项），或回复卡片消息输入自定义答案。在桌面端或其他路由作答后，卡片会原位更新并清掉按钮。

## 群内命令

`/help` `/status` `/id` `/session` `/steer` `/stop` `/sync` `/allow` `/deny` `/admin` `/unadmin` `/context` `/bind` `/unbind` —— 回发都会正确落到对应话题。

## 权限

| 权限 | 用途 |
| --- | --- |
| `agent.inject` | 把 Telegram 消息投递到绑定的会话 |
| `agent.injectTrusted` | 仅用于管理员的消息：不带 sender 以可信方式投递，模型直接按指令执行。普通用户的消息仍带 sender、由宿主按外部数据包裹。宿主不接受可信投递时自动降级为外部消息并在聊天里提示一次。升级时宿主会提示确认此权限。 |
| `session.focus` | 在面板里点目标会话时切换过去 |

## 迁移

从 0.4.0 升级时，旧的绑定、排队消息与上下文自动迁移为按路由存储，不会丢绑定。从 1.0 升级只新增空的管理员名单。从 1.2 升级时「信任本群匿名管理员」一律为关，可信发言频道名单为空。
