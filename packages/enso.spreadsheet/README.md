# Spreadsheet

在 Enso 的文件面板里打开并编辑表格。`.csv`、`.tsv`、`.xlsx`、`.ods` 默认用这个查看器打开。

网格里改单元格，公式栏会显示原始内容。以 `=` 开头的是公式，算完后把结果显示在格子里；出错时用红色画出 `#DIV/0!`、`#REF!`、`#VALUE!`、`#NAME?`、`#N/A`、`#NUM!` 和循环引用 `#CYCLE!`。选中多格时，底栏给出计数、求和与平均。右键可以在上方或下方插入行、在左侧或右侧插入列、删除行列、清除内容。撤销和重做也在公式栏上。

界面跟随 Enso 的浅色和深色主题。

## 保存

查看器只通过 Enso 的文件协议交回文本：`enso.file.text` 读入，`enso.file.update` 写回编辑区，由你保存。插件拿不到磁盘路径，也不会自己写文件。

- `.csv` 用逗号，`.tsv` 用制表符。公式按你输入的原文保存，所以重新打开后还会计算。含逗号、引号或换行的单元格会按 CSV 规则加引号。这两种格式只有一张工作表，方便用 Excel 或别的表格软件打开。
- `.xlsx` 和 `.ods` 保存为无空字节的文本工作簿（多工作表、公式、隐藏表）。Enso 读文件时会拒绝含空字节的二进制内容，真实的 Excel / ODS 压缩包在交给查看器之前就会被宿主拦住，因此这里不能原地改写那种压缩包。在 Enso 里新建的 `.xlsx` / `.ods` 可以继续用本插件打开和编辑。

支持的公式包括四则运算、比较、文本连接、百分号，以及 `SUM`、`AVERAGE`、`MIN`、`MAX`、`COUNT`、`COUNTA`、`COUNTIF`、`SUMIF`、`IF`、`IFERROR`、`AND`、`OR`、`NOT`、`ROUND`、`ABS`、`INT`、`MOD`、`POWER`、`SQRT`、`CONCAT`、`LEFT`、`MID`、`RIGHT`、`LEN`、`UPPER`、`LOWER`、`TRIM`。参数之间用逗号或分号都可以。插入或删除行列时，引用会跟着移动；被删掉的单元格变成 `#REF!`。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| 方向键 | 移动当前单元格 |
| Shift + 方向键或 Shift + 点击 | 扩展选区 |
| Ctrl/Cmd + 方向键 | 跳到数据边缘 |
| Tab / Enter | 向右 / 向下确认并移动 |
| F2 或双击 | 编辑单元格原内容 |
| Esc | 放弃本次编辑 |
| Delete | 清除选区 |
| Ctrl/Cmd + Z / Y | 撤销 / 重做 |
| 右键或 Shift + F10 | 行列菜单 |

## 权限

| 权限 | 用途 |
| --- | --- |
| `ui.view` | 作为文件查看器打开表格 |
