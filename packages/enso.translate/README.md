# 双语对照翻译

把模型的思考过程和回复正文译成目标语言。原文仍由 EnsoCode 显示，译文紧跟在后面。

翻译请求发往 B 站 Index-Translate 的免费接口，同时最多 3 个。失败时译文位置会出现可点击的「重试」。

## 设置

| 项 | 说明 | 默认 |
| --- | --- | --- |
| 翻译思考过程 | 关闭后思考正文只显示原文 | 开 |
| 翻译回复正文 | `关闭` / `手动` / `自动` | 手动 |
| 目标语言 | 中文、英文、日文、韩文、法文、德文、西班牙文、俄文 | 中文 |
| 翻译模型 | Index-Translate 35B / 9B / 2B | 35B |

回复正文为「自动」时默认显示译文，为「手动」时默认不显示。回复下方的「翻译 / 显示原文」只作用于这一条消息。「关闭」时不显示按钮，也不追加译文。整段按与思考过程相同的规则判定后没有任何可译段落时，也不显示按钮。只有正文定稿后才翻译，流式输出中不请求。

配置由后台读取。界面缓存几秒，之后新渲染的内容使用新配置。

## 结构保护

发给模型前，下列内容会换成 `⟦0⟧`、`⟦1⟧` 这样的占位符，译文回来后再换回原文。每个占位符必须恰好出现一次，否则这条译文不显示。

- 行内代码（含多反引号）
- Markdown 链接和图片（整段 `[...](...)` / `![...](...)`）
- 自动链接 `<http...>`、裸 URL
- HTML 标签
- `$...$` 行内公式
- 像文件路径的词：含 `/` 或 `\` 且带扩展名，或以 `./`、`../`、`~/`、`/`、盘符开头

整段只剩占位符和标点时不翻译。加粗、斜体标记可能在译文里丢失。

## 限制

- 是否「已经是目标语言」只看文字占比：中文为汉字不少于一半且没有假名；日文为含有平假名或片假名；韩文、俄文为谚文、西里尔字母不少于一半；英文、法文、德文、西班牙文都按拉丁字母不少于一半，彼此分不开。
- 因此纯汉字的日文可能被当成中文而跳过；拉丁语之间也不会互相翻译。
- 占比的分母只算字母，不算数字、空白和标点。
- 回复叶子依赖宿主的 `message.leaf` 挂点。更早的宿主会忽略正文翻译，思考翻译仍然可用。
- 代码块整段不翻译。思考过程里的行内代码不会单独占位，只有回复正文会。
