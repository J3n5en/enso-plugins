## 功能

- 推荐列表、搜索、分页加载
- 剧集详情与分集选择，看过的集数会标灰
- 侧栏内播放，边下边播，360p 到 1080p 可切换清晰度，播完自动下一集
- 观看历史：记住每部剧看到第几集、第几秒，点一下接着看
- 缓存管理：自动只保留最近 6 集视频和 300 张封面，历史页可一键清理

不需要安装 ffmpeg，也不需要登录。

## 播放器

自带一套为侧栏定制的播放器，替代浏览器原生控件：

- 控件在播放时自动隐藏，移动鼠标出现；顶部显示集数和剧名
- 进度条显示已缓冲部分，悬停可预览时间，可拖动
- 倍速 0.75x 到 3x、清晰度在播放器里直接切换，倍速和音量会记住
- 下一集按钮、画中画、铺满整个侧栏（双击画面也可以）
- 缓冲时显示加载动画，操作时有轻提示

| 快捷键 | 作用 |
| --- | --- |
| 空格 / K | 播放、暂停 |
| ← / → | 快退、快进 5 秒 |
| ↑ / ↓ | 调节音量 |
| M | 静音 |
| F / Esc | 铺满侧栏、退出铺满 |
| N | 下一集 |
| &lt; / &gt; | 降低、提高倍速 |

快捷键需要先点一下播放器让它获得焦点。

## 环境要求

- 带 Enso 插件系统的 EnsoCode 桌面版
- 推荐 macOS。播放用的是 HEVC（H.265），依赖系统硬件解码；封面是 HEIC 格式，macOS 上用系统自带的 `sips` 转码
- 其他系统上，如果装了 ffmpeg 会用它转封面，没装就不显示封面，不影响播放；HEVC 能否播放取决于系统和显卡

## 安装

### 从 GitHub 链接安装（推荐）

1. 打开 EnsoCode，进入 **设置 → 插件**，找到 **Enso plugins** 一栏。
2. 在链接输入框里粘贴：

   ```
   https://github.com/J3n5en/enso-hongguo
   ```

3. 点 **从链接安装**，在弹出的预览里确认插件信息和权限（只申请了 `ui.view`，即侧栏页面），点确认。
4. 在插件列表里把 **红果短剧** 打开（启用）。

### 从本地目录安装

```bash
git clone https://github.com/J3n5en/enso-hongguo.git
```

然后在 **设置 → 插件 → Enso plugins** 里点 **Install from folder**，选中克隆下来的目录，确认并启用。

仓库里已经带了 `node_modules`，不需要再执行 `npm install`：EnsoCode 安装插件时会原样复制目录，不会帮你装依赖。

### 打开播放器

1. 打开或新建任意一个会话（侧栏要有会话才会出现）。
2. 展开右侧面板，点 **新建标签页（+）**。
3. 在菜单里选 **红果短剧**。

## 更新

- 从 GitHub 链接安装的，EnsoCode 会定期检查 `enso-plugin.json` 里的版本号，有新版时插件行会提示 **更新**，也可以手动点 **检查更新**。
- 任何方式安装的都可以在插件行点 **从来源重新安装** 拉取最新代码。

## 缓存与数据

插件数据都在 EnsoCode 的插件数据目录里（macOS）：

```
~/Library/Application Support/enso-code/extension-plugins/data/enso.hongguo/
├── video/           最近看过的视频，自动只保留 6 集
├── covers/          封面，自动只保留 300 张
└── anonymous.json   匿名设备身份
```

- 一般占用几十到一百多 MB。
- 在 **历史** 页能看到当前占用，点两次 **清理缓存** 即可清空视频和封面（正在播放的那集除外）。观看历史不受影响。
- 卸载插件时，EnsoCode 会把上面整个目录一起删除。

## 实现说明

- 数据来自 [openhongguo](https://github.com/beilunyang/openhongguo)（Apache-2.0），以匿名设备身份访问。
- 侧栏页面跑在沙盒 iframe 里，不能直接访问外网，也不能用 `http(s)` 地址播放媒体。所以视频由插件后台进程下载，在本机转成分段 MP4，再分块传给页面里的 MediaSource 播放。
- 视频流本身是加密的（cenc-aes-ctr），`remux.mjs` 在本机用 Node 自带的 `crypto` 解密并重新封装，不依赖 ffmpeg。

| 文件 | 作用 |
| --- | --- |
| `enso-plugin.json` | 插件清单 |
| `main.mjs` | 后台进程：列表、搜索、分集、封面、下载与分块传输、缓存管理 |
| `remux.mjs` | 解密并把普通 MP4 转成分段 MP4 |
| `index.html` | 侧栏页面：列表、详情、播放流程、历史 |
| `player.js` / `player.css` | 播放器界面 |

## 常见问题

**提示「请求太频繁」或「匿名设备被限制」**
红果服务端对匿名访问有频率限制，稍等一会儿再试。插件会自动重置匿名设备并重试。

**一直显示「解析中」或黑屏**
先确认系统支持 HEVC 硬件解码。可以在插件行查看日志；也可以清理缓存后重新打开那一集。

**突然全部不能用了**
这是非官方接口，服务端随时可能调整。请关注本仓库或 openhongguo 的更新。
