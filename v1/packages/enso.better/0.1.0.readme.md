# Better Prompt

移植自 [nicobailon/pi-better](https://github.com/nicobailon/pi-better)，改写提示用的是 Felix Rieseberg 在 [How to be more ambitious](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/#depth) 里的「Depth」提示。

## 用法

1. 在输入框写下想法，点输入框左下角的按钮。
2. 右侧栏打开 Better 页面：进度条走过「阅读代码和文件 → 四个问题 → 写出提示词」，列出它读过的文件和搜索，实时显示四个问题的回答。
3. 完成后改进后的提示词替换输入框文字，按回车才会发送。等待期间你新输入的内容保留在下方；不满意点「还原」。

输入框为空时，改写的是当前会话里正在进行的任务（连同你已经给过的反馈）。运行中再点按钮或点侧栏的「取消」即可停止。

## 它做了什么

- 从当前会话分叉一个只读代理（`agent.run`，和 pi-better 的 `--fork` 一样）：同一个模型、带上完整对话，第一轮就能读到会话的提示缓存；只有 read / grep / find / ls（开了沙箱脚本时还有只能调这几个工具的 codemode）能执行，不能改文件、不跑命令，不进会话记录，也不打断主会话。
- 代理先读相关代码和文档，再回答四个问题：高手会多做什么、最原始的材料是什么、具体用什么方法和工具、除了你我之外什么能证明结果正确；最后把提示词改写成要求这些的版本。
- 草稿里有文件或会话引用时不能整体替换，提示词会插入到光标处；侧栏也可以随时「插入输入框」或「复制」。

## 设置

- **对话上下文**：`conversation`（缺省）从当前会话分叉，带上完整对话；`none` 只看草稿和代码。
- **完成后自动关闭侧栏（秒）**：缺省 5 秒；倒计时期间在侧栏里点击、滚动或按键就保留。填 0 不自动关闭。

需要 Enso 0.3.8 或更新版本。
