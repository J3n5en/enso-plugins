# Session Bridge（跨会话桥）

让同一项目下的多个活跃会话在右侧栏的「会话桥」群聊室中互相提问、委派核查并回传结论。

## 功能亮点

- **跨会话提问（1 对多）**：会话 A 可通过 `bridge_ask` 同时向同项目的会话 B、会话 C 提问，支持同步等待汇总回答（`wait: true`）或后台异步投递回传（`wait: false`）。
- **双通道回答回收**：目标会话既可调用 `bridge_reply` 主动回传精炼结论，也可在当前轮自然结束时由 `agent_end` 事件自动捕获回复。
- **Bot 群聊风格侧栏**：
  - 顶部实时展示同项目所有活跃会话成员、状态呼吸灯（思考中 / 等待审批 / 空闲），点击任意会话一键切换聚焦；
  - 中部以多成员群聊时间线展示「谁 `@` 了谁」、各目标会话的实时思考状态与引用回复气泡；
  - 底部支持用户直接勾选多个 `@目标会话` 发送群聊消息或广播。
- **前后向兼容**：在新版 EnsoCode 上触发跨会话提问时会自动展开右侧栏并定位到「会话桥」标签页；在旧版 `main` 上支持手动从右侧栏 `+` 打开「会话桥」标签页并自动同步完整群聊历史。

## 使用前提

安装后请前往 **设置 → 插件 → Session Bridge**，开启 **「允许向任意运行中的会话发送消息」**（或执行 `enso-server plugin inject-anywhere enso.bridge`）。
