# Kanban

项目看板。同一项目的所有会话共享一块看板，人和 agent 都能创建、编辑、拖动卡片，用来分派和跟踪任务。

## 使用

1. 打开侧栏「看板」。每个项目一块看板，默认有「待办」「进行中」「完成」三列。
2. 新建卡片，填写标题和描述。拖动卡片调整顺序或换列。
3. 列可以新增、改名、移动；只有空列能删除。
4. 卡片可以绑定会话，之后点卡片即可跳到该会话。
5. 把卡片发送到会话：
   - 绑定的会话；
   - 当前会话，立即开始并绑定；
   - 新建会话，预填内容并绑定；
   - 只放进输入框，不发送。

   发送的内容会提示 agent 用 `kanban_upsert` 更新卡片进度。

每块看板最多 20 列、500 张卡片，保存在插件数据目录（`boards/`）。

## Agent 工具

| 工具 | 作用 |
| --- | --- |
| `kanban_list` | 列出看板的列和卡片 |
| `kanban_upsert` | 新建或更新、移动卡片；agent 新建的卡片默认绑定到它所在的会话 |
| `kanban_column` | 新增、改名、删除、移动列 |
| `kanban_delete` | 删除卡片 |

## 设置

把卡片发送到当前会话以外的会话时，需要在 设置 → 插件 → Kanban 打开「允许向任意运行中的会话发送消息」。

## 权限

| 权限 | 用途 |
| --- | --- |
| `ui.view` | 打开侧栏页面 |
| `agent.tool` | 提供上面的 Agent 工具 |
| `agent.inject` | 把卡片内容发送到会话 |
| `composer.draft` | 把卡片内容放进输入框 |
| `session.read` | 显示本项目的会话列表供绑定 |
| `session.focus` | 点击卡片时切换到绑定的会话 |
| `session.create` | 新建会话并发送卡片 |
