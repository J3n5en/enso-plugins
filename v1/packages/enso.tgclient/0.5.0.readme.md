# Telegram 客户端

在 EnsoCode 侧栏里登录自己的 Telegram 账号（MTProto，基于 [GramJS](https://github.com/gram-js/gramjs)），像官方客户端一样聊天。

## 使用

1. 打开侧栏「Telegram」，填入带区号的手机号，获取验证码登录；开了两步验证的再输入云密码。
2. 国内网络在 设置 → 插件 → Telegram 客户端 填写代理：`socks5://127.0.0.1:7890` 或 MTProxy 链接。

登录信息只保存在插件数据目录（`account.json`），卸载插件即删除。插件常驻运行，侧栏关着也能收到新消息通知。

## 功能

- 会话列表：置顶、未读数、@ 提醒、静音、在线状态、搜索
- 聊天分组：同步手机端建好的分组（文件夹），顶部标签切换，带未读数，另有「已归档」
- 会话列表滚动到底部自动加载更多
- 右键消息：快捷表情回应、回复、复制、编辑、删除；自己发的消息可看谁已读及已读时间（私聊、100 人以内的群、7 天内）
- 视频边下边播（50MB 以内；少数索引在文件末尾的视频要下完才能播）
- 相册：收到的多图合成一组显示，大图里左右切换；选多张图片或视频发送时自动合成相册
- 话题（论坛群）：先显示话题列表（置顶、未读、已关闭），点进话题收发消息；聊天顶部有话题标签栏随时切换，「全部」把所有话题的消息合在一起看；各话题草稿分开
- 群里切换发言身份：以个人或自己管理的频道身份发言
- 聊天：实时收发、回复、编辑（↑ 键编辑上一条）、删除自己的消息、表情回应、富文本、链接预览、已读回执、上滑加载历史
- 表情与贴纸面板：常用表情、已安装贴纸包、最近与收藏的贴纸
- 机器人：内联按钮（回调、链接、切换内联、复制）、回复键盘、空聊天一键「开始」
- 媒体：图片、贴纸、动图、语音、视频（≤50MB 侧栏内播放）、文件下载到「下载」文件夹
- 发送图片和文件（≤20MB），支持粘贴图片
- Agent 工具：`tg_current_chat` 获取侧栏当前打开的对话和最近消息、`tg_list_chats` 列出聊天、`tg_search_chats` 搜索聊天/联系人/公开群和频道、`tg_list_topics` 列出论坛群的话题、`tg_get_messages` 查看聊天记录、`tg_search_messages` 搜索消息（单个聊天或全部）、`tg_send_message` 以本人身份发消息、`tg_mark_read` 标为已读、`tg_wait_messages` 等新消息（长轮询，带 cursor 不漏消息）、`tg_watch` / `tg_unwatch` 订阅新消息（攒几秒投递到会话并自动开始新一轮；`keywords` 只投递含关键词或 @我、回复我的消息，`tg_wait_messages` 同样支持，需在插件设置里打开「允许向任意运行中的会话发送消息」；侧栏顶部的眼睛图标列出所有订阅，可查看投递情况并取消）；聊天可用 id、@用户名或名称指定，不填则用侧栏当前打开的对话（论坛群里还会沿用当前话题），需先在侧栏登录
- 订阅只在 `tg_unwatch` 或取消订阅时结束：投递失败（会话没在跑、没开跨会话授权、限流）不会删除订阅，消息留在队列里按 5 秒 → 5 分钟指数退避重试，连续失败 5 次才弹一次系统通知，侧栏订阅列表里能看到最后的失败原因
- 投递细节：处理期间在该聊天显示「正在输入」（每 4 秒刷新，发出回复或 5 分钟无动作即停）；@我或回复我的消息跳过安静期立即投递，队列里攒着的普通消息并进同一批只投一次；自己发出去的消息同样会投递（手机上手打也算），只有本插件自己发出的消息会被跳过，避免回复把自己再唤醒一次；图片会随消息一起转达，最多 4 张
- 投递节奏可调：`debounceSec`（安静期，默认 3 秒，最长 1 小时，连发的几条合成一批）和 `minIntervalSec`（两次投递的最小间隔，默认 0 不限，最长 24 小时）——群消息很密集时把它设成 60 或 300，避免每几秒就唤醒一次 agent

## 开发

`vendor/gramjs.mjs` 是打包产物，不要手改。更新 GramJS：

```bash
cd scripts/tgclient && npm ci && node build.mjs
```
