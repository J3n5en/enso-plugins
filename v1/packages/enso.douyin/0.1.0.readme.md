# 抖音推荐流 · EnsoCode 侧栏插件

在 EnsoCode 的侧栏里刷抖音推荐流：全屏竖划切换、直接播放、显示作者与互动数据。

> **非官方项目，仅供学习与技术研究。** 请勿用于商业用途或批量抓取。

## 功能

- 全屏竖划刷推荐流（滚轮 / 触控板 / ↑↓ / j k）
- 自动播放、静音启动，点画面暂停（中央有暂停标），点右上角 🔊 开声音
- 显示作者、描述、音乐名，以及点赞 / 评论 / 转发数
- 点 `⧉` 复制分享链接（`https://www.douyin.com/video/{id}`）
- 没有音轨的作品会标「无音轨」
- 快刷到底自动续拉下一批，按作品 id 去重
- 左上角 ↻ 换一批

## 快捷键

| 键 | 作用 |
| --- | --- |
| ↑ / ↓ 或 k / j | 上一条、下一条 |
| 空格 / 点击画面 | 暂停、播放 |
| M | 静音开关 |
| R | 换一批 |

## 原理

抖音的推荐流接口不校验请求签名。插件只用公开的 HTTP 接口，在插件数据目录里生成一组
**游客设备号**，带上公共参数和游客 cookie 就能拿到一批新的推荐内容。

- 不需要越狱设备、不需要登录、不需要签名
- 每次请求返回一批全新内容（推荐流没有游标）
- 签名只在搜索、用户主页、作品列表、评论这些接口上才强制，本插件不涉及

## 播放是怎么做的

插件页面被宿主 CSP 限制成 `media-src data: blob:`，远程视频地址直接播会被拦。所以：

1. 主进程把视频下载到插件数据目录（`media/`），页面按 512 KB 分块取回
2. **分片 mp4**（`moov` 含 `mvex`）走 MSE，边下边播
3. **整段 mp4**（抖音多数作品）MSE 会直接拒收，退回整段拼 `Blob` 播放
4. 默认取 `bit_rate` 里最低的一档（约 400 kbps），单条体积小 3–5 倍
5. 滑到当前这条时后台预取下一条，滑过去基本秒开

宿主把 renderer 返回值限制在 1 MB 内，所以分块是 512 KB（base64 后约 699 KB）。

## 安装

打开 EnsoCode，进入 **设置 → 插件**，找到 **抖音推荐流** 打开即可。

本地开发时也可以用「从本地目录安装」指向本仓库的 `packages/enso.douyin`。

## 环境要求

- 带插件系统的 EnsoCode 桌面版
- 视频是 HEVC（H.265），依赖系统解码能力；macOS 上走系统硬件解码

## 数据

插件数据目录里只有两样东西：

- `guest.json`：自动生成的游客设备号（删掉就会重新生成一组）
- `media/*.mp4`：视频缓存，保留最近 3 个并清理 24 小时前的

## 已知限制

- 视频地址带时效参数，长时间挂着会失效，点 ↻ 换一批即可
- 长视频（3 分钟以上）首播要等几秒到十几秒，会显示下载百分比
- 搜索、用户主页、作品列表、评论需要签名，本插件不覆盖
